---
name: spec
description: Interview user one question at a time then produce a written feature spec
---

Ask the user questions one at a time to understand the feature.
Do not ask the next question until the previous one is answered.
Cover: what it does, who uses it, edge cases, error states, constraints.
After all questions, produce a written spec with:
- Feature description
- Edge cases
- Files likely affected
- Implementation approach
Do not write any code.
